# 할리갈리 — 타자 대전

종을 치는 대신 **과일 이름을 먼저 타자로 치는** 사람이 판을 가져가는 온라인 할리갈리.

## 실행

```bash
npm install     # 최초 1회
npm start       # http://localhost:8788
```

## 친구와 하기

### 같은 와이파이

서버를 켠 뒤 친구에게 **`http://<내 IP>:8788`** 을 알려준다.
IP 확인: `ipconfig getifaddr en0`

macOS가 "들어오는 연결을 허용하시겠습니까?" 라고 물으면 **허용**을 눌러야 한다.

### 다른 네트워크 (외부 인터넷)

```bash
npx cloudflared tunnel --url http://localhost:8788
```

출력되는 `https://....trycloudflare.com` 주소를 공유하면 된다.
터미널을 끄면 주소도 사라진다. (WebSocket을 그대로 통과시키므로 게임이 정상 동작한다.)

## 배포 (Render)

이 저장소에는 `render.yaml`이 들어 있어서 Render가 설정을 알아서 읽는다.

1. GitHub에 push
2. [dashboard.render.com](https://dashboard.render.com) → **New → Blueprint**
3. `41ways/halligalli` 저장소 선택 → **Apply**

빌드가 끝나면 `https://halligalli-xxxx.onrender.com` 주소가 나온다. 그 주소를 친구에게 주면 끝.
이후에는 `main`에 push할 때마다 자동으로 다시 배포된다.

무료 플랜은 **15분 동안 아무도 안 들어오면 잠들고**, 그 뒤 첫 접속이 40~60초 걸린다.
같이 하기로 한 시간 조금 전에 미리 한 번 열어두면 깨어 있는 상태로 시작할 수 있다.

## 규칙

- 카드 56장 — 바나나 / 라임 / 딸기 / 포도 × 1~5개 (정품과 동일한 분포)
- 가운데 **종**을 두고 둘러앉는다. 자기 손패 뭉치는 자기 쪽 바깥, 펼친 카드는 종 주위에 모인다
- 방장이 대기실에서 시작하면 카드가 나눠지고, 테이블 **한가운데 뜨는 '게임 시작'** 을 방장이 눌러야 첫 차례가 열린다
- 자기 차례에 **마우스로 클릭**해서 카드를 한 장 깐다 (손패에서 뽑혀 공중에서 뒤집히며 종 옆에 놓인다)
- 펼쳐진 카드에서 **같은 과일이 정확히 5개**가 되면, 그 과일 이름을 **타자로** 친다
  - 한글·영어 모두 인식하고 Enter 없이 즉시 판정된다
  - 클릭으로는 칠 수 없다. 오직 타자
- **5개가 떠 있는 동안에는 아무도 카드를 깔 수 없다** — 누군가 칠 때까지 판이 멈춘다
- 맞히면 테이블의 카드를 전부 가져가고, 틀리면 다른 플레이어에게 한 장씩 준다
- 손패와 앞면이 모두 떨어지면 탈락. 마지막까지 남으면 승리

## 차례 표시

지금 누구 차례인지 네 군데서 동시에 보인다.

- 보드 위 오른쪽 알약 — 내 차례면 금색으로 채워져 깜빡이고 "내 차례 — 카드를 뒤집으세요"
- 그 사람 손패에 금색 링이 돌고, 이름표에 **차례** 배지가 붙는다
- 나머지 사람 이름표는 한 톤 흐려진다
- 내 차례면 테이블 테두리 전체가 금색으로 바뀐다

## 판정 표시

- 종을 친 순간 화면 위에 **누가 맞혔는지 / 누가 잘못 쳤는지**가 큰 배너로 뜬다 (초록=성공, 빨강=오답)
- 해당 플레이어의 자리가 같은 색으로 번쩍이고 **+13 / −2** 처럼 주고받은 장수가 뜬다
- 각 자리에 **종 N · 오답 N** 누적 기록이 남는다
- 게임이 끝나면 **최종 순위표**가 뜬다 — 등수, 남은 카드, 종/오답 횟수

## 봇

- 방장이 대기실에서 봇을 넣고 뺄 수 있다 (최대 6인)
- **사람이 2명 이상이면 봇은 종을 치지 않는다** — 카드만 넘겨주는 딜러 역할
- **혼자 할 때만** 봇이 직접 종을 친다 (실력 3단계)

## 모드

방을 만들 때 **기본**과 **익스트림** 중에 고른다 (방장은 대기실에서도 바꿀 수 있다).

### 기본 — 56장

- 카드 한 장에 같은 과일 1~5개. 바나나 / 라임 / 딸기 / 포도
- 펼쳐진 카드에서 **같은 과일이 정확히 5개**면 그 **과일 이름**을 친다

### 익스트림 — 72장

과일 카드는 한 장에 **과일 종류가 1~3가지**, 같은 종류는 하나씩만 그려져 있다.

| 카드 | 종류 | 장수 |
|---|---|---|
| 과일 1종 | 4종 (과일마다) | 4장씩 = 16 |
| 과일 2종 | 6종 (조합 전부) | 4장씩 = 24 |
| 과일 3종 | 4종 (딸바포·딸바라·딸라포·라바포) | 6장씩 = 24 |
| 동물 | 코끼리 · 원숭이 · 돼지 | 3 · 3 · 2 = 8 |

개수를 세는 게 아니라 아래 네 가지 중 하나가 성립하면 친다.

| 칠 말 | 조건 |
|---|---|
| `짝` | 그려진 **과일 조합이 똑같은 카드가 두 장** 펼쳐져 있을 때 |
| `코끼리` | 코끼리 카드가 있고, 테이블에 **딸기가 하나도 없을** 때 |
| `원숭이` | 원숭이 카드가 있고, 테이블에 **라임이 하나도 없을** 때 |
| `돼지` | 돼지 카드가 보이면 **조건 없이** 바로 |

익스트림에는 "5개" 규칙이 없고, 과일 이름을 쳐도 아무 일도 일어나지 않는다.
장수는 `server.js` 의 `EX_COPIES` 와 `ANIMAL_COPIES` 에서 바꾼다.

## 배치

카드 위쪽 **크게보기** 스위치로 두 가지 배치를 오간다. 선택은 브라우저에 저장된다.

| | 배치 | 카드 크기(세로 820px 기준) |
|---|---|---|
| 끔 (기본) | 종을 가운데 두고 둘러앉기. 손패는 자기 쪽 바깥 | 125px |
| 켬 | 펼친 카드가 가로 한 줄, 손패는 자기 카드 바로 아래 | 190px |

보드는 화면에서 남는 세로를 전부 가져가고, 카드 크기는 그 높이에 맞춰 자동으로 계산된다.

## 모양

모서리·테두리·그림자는 CSS 변수로 묶여 있고, 기본은 **시안 2번 «살짝»** 이다
(테이블 12px · 카드 8px · 알약 없음). `public/app.js` 아래쪽

```js
document.documentElement.dataset.shape = 'soft';
```

한 줄만 바꾸면 `round · soft · sharp · zero · cut · line · thick` 로 갈아끼운다.
일곱 가지를 실제 화면으로 비교하려면 `/shapes.html` 을 연다.

## 테마

우측 상단 선택기로 언제든 바꿀 수 있다. 선택은 브라우저에 저장된다.

| 테마 | 느낌 |
|---|---|
| 딥 그린 펠트 | 카지노 테이블. 초록 펠트 + 골드 |
| 네온 아케이드 | 보라 배경 + 시안 형광. 오락실 |
| 크래프트 페이퍼 | 크림색 종이 + 나무톤. 보드게임 박스 감성 (기본) |
| 미드나잇 미니멀 | 무채색 다크 + 앰버 포인트 하나 |
| 캔디 팝 | 파스텔 핑크 + 보라. 가볍고 통통 (밝은 테마) |

색은 전부 CSS 변수로 빠져 있어서, `public/style.css` 아래쪽 `html[data-theme="…"]` 블록만 손대면 새 테마를 추가할 수 있다.

소리는 **기본이 무음**이다. 상단 🔇 버튼을 누르면 켜지고, 선택은 브라우저에 저장된다.

규칙은 우상단 **?** 버튼으로 언제든 연다. 지금 방의 모드에 맞는 규칙만 보여준다.
게임 화면에는 안내가 따로 뜨지 않는다 — 판만 보인다.

## 알아두면 좋은 동작

- 누군가 종을 친 뒤 1.4초는 판정 정지 구간이다. 이때 친 글자는 무시되고 입력창이 비워진다
- 서버가 입력을 무시할 때는 이유를 돌려준다. 화면에 아무 반응이 없는 상태로 남지 않는다
- 다 같이 조건을 놓쳐 판이 멈추면 8초 뒤 안내가 뜨고, 봇이 있으면 봇이 판을 되살린다

## 모드 관리

기본과 익스트림이 섞이지 않도록, 두 모드의 차이는 **각각 한 곳에만** 있다.

- `server.js` 의 `MODES` — 덱 · 칠 수 있는 말 · 종 조건 · 판정
- `public/app.js` 의 `MODES` — 칠 수 있는 말 · 입력창 안내문 · 잘못된 모드 안내

바깥 코드는 `modeOf(room)` / `curMode()` 로만 접근한다. `if (extreme)` 분기를 새로 만들지 말 것.

서버는 켤 때 두 모드의 덱을 **자체 점검**하고 구성을 찍는다. 어긋나면 그 자리에서 죽는다.

```
  기본     56장 (과일 56 · 동물 0) · 칠 수 있는 말: 바나나 / 라임 / 딸기 / 포도
  익스트림  72장 (과일 64 · 동물 8) · 칠 수 있는 말: 짝 / 코끼리 / 원숭이 / 돼지
```

서버를 켜 둔 채로 회귀 검사를 돌린다:

```bash
npm test
```

덱 장수, 카드 구성, 종 조건, 다른 모드 말 거부까지 14가지를 확인한다.

## 구조

```
server.js        게임 서버 — 덱·판정·차례·타이머·봇을 모두 서버가 관리
public/index.html
public/style.css
public/app.js    화면 렌더 + 입력
```

서버가 권위를 가지므로 클라이언트를 조작해도 판정을 속일 수 없다.
누가 먼저 쳤는지는 서버 도착 순서로 정해진다.
